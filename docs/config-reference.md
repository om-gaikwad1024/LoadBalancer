# Configuration reference

Every field is **required**: the loader rejects a config with any missing, unknown, mistyped or
out-of-range field and keeps the last good config (plan IV.14). Every timeout, limit,
threshold and size lives here; none are hard-coded in the engine.

Durations are integers in milliseconds unless a field says otherwise; sizes are integers in bytes.

_No fields yet. Step 1.1 adds the first schema; each later step documents the fields it adds._
